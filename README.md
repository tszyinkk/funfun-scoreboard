# 分分計

一個適合球類、卡牌及桌遊的靈活計分 Web App。

## 使用方法

直接打開 `index.html`，或在這個資料夾執行：

```bash
python3 -m http.server 4173
```

然後前往 `http://localhost:4173`。

## 功能

- 主頁分開四個入口：兩隊比賽、香港麻雀、首家抽籤及鋤大D四人計分
- 鋤大D 每鋪只需揀贏家及輸入其餘玩家剩牌，自動計算 8–9 張起炒、10–12 張雙炒、13 張三炒
- 香港麻雀計番模式：開局只需選起糊番數、東圈／半莊／自訂局數及最高番數
- 新牌局預設簡易香港計分級別（3番1倍、4番2倍、5–6番4倍、7–9番8倍、10–12番16倍、13番或以上32倍），亦可一按轉用香港朋友枱常見的半辣上或逐番跳倍的辣辣上；底數及自訂方式收在進階設定
- 麻雀牌局會按四位玩家輪流做莊追蹤圈數與圈風，支援流局、提早結算、未完成輸入確認及完整排名
- 已結算的麻雀對局會留在本機紀錄，可在主頁重新開啟查看；最多保留最近 50 場
- 獨立首家抽籤模式：不用輸入姓名，大家在螢幕任何位置同時按住，倒數後隨機閃出首家
- 每個玩法各自保存多個對局，可直接繼續或刪除紀錄
- 中文／英文介面一鍵切換，語言選擇會留在本機
- 每位參加者都有本局分數與總分
- 直接點按大分數位置加 1 分，亦可減分及手動調整總分
- 可開始及暫停的比賽計時器
- 完局時可選「勝方 +1」、「累加本局」或「只手動」
- 支援最高分勝或最低分勝
- 比分紀錄、撤銷及自動儲存
- 球類模式橫屏全螢幕左右分區，中間放計時、設定及完局控制；直屏時提示轉向
- 鋤大D、麻雀維持直屏，適合手機逐局記分
- 手機、平板及電腦自適應版面

所有資料只會保存在瀏覽器的本機儲存空間，不會上傳。

## GitHub Pages 與離線使用

1. 將整個資料夾推送到公開 GitHub repository。
2. 在 repository 的 **Settings → Pages**，選擇 **Deploy from a branch**。
3. 選擇 `main` branch 及 `/ (root)`，然後儲存。
4. 使用者第一次需要有網絡開啟 GitHub Pages 網址；完成載入後即可離線使用。

網站已包含 Service Worker、Web App Manifest 及安裝圖示。在 iPhone／iPad 可使用 Safari 的「加入主畫面」，Android 或桌面 Chrome 可選擇「安裝應用程式」。每部裝置的比分分開儲存，不會互相同步。
