# Third-party assets

## Lucide Icons

- Library: Lucide Icons
- Source: https://lucide.dev/ and https://github.com/lucide-icons/lucide/tree/main/icons
- Licence: ISC License
- Local copies: `assets/icons/lucide/`

The app uses the official Lucide SVGs for sports controls: house, undo-2,
sliders-horizontal, play, pause, timer-reset, refresh-cw, trash, trophy, flag,
check, skip-forward and pencil. The SVG source files retain Lucide's
`currentColor` strokes; the interface applies them through local CSS masks so
they inherit the control colour and remain usable offline.
